\# Secure AWS VPC Infrastructure with Application Load Balancer



\## Project Overview

This project demonstrates AWS networking concepts using a custom VPC, EC2 instances, and an Application Load Balancer.



\## Objectives

\- Understand VPC and subnet networking.

\- Practice secure access to a private EC2 instance through a jump host.

\- Host a static HTML webpage on EC2.

\- Route web traffic through an Application Load Balancer.

\- Validate target health using AWS CLI.



\## Technologies

\- Amazon VPC

\- Amazon EC2

\- Application Load Balancer (ALB)

\- Target Groups

\- Security Groups

\- AWS CLI

\- Linux and SSH

\- HTML



\## Learning Outcomes

Practiced AWS networking, private-instance access, load balancing, and infrastructure validation.

This repository documents a learning project. Features listed above should be marked complete only after they have been configured and verified.
